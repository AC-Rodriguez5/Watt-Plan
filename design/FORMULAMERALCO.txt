
1. Core Formulas (Per Line Item)

• Generation Charge (Discountable Base | Vatable)
Gen = kWh × R_gen
• Transmission Charge (Discountable Base | Vatable)
Trans = kWh × (R_trans + R_ancillary)
• System Loss Charge (Discountable Base | Vatable)
SysLoss = kWh × R_sysloss
• Distribution Charge (Meralco) (Discountable Base | Vatable | Tiered by kWh)
Dist = (kWh × [R_dist_tier + R_supply + R_metering + R_awat_total]) + F_supply + F_metering
• Senior Citizen Line (Deduction Line if Eligible, else Subsidy)
	• IF isRegisteredSenior == true AND kWh <= 100: Senior = -0.05 × (Gen + Trans + SysLoss + Dist)
	• ELSE: Senior = kWh × R_senior_sub
• Universal Charges (UC) (Non-Discountable | Tax-Exempt)
UC = kWh × (R_uc_spug + R_uc_red + R_uc_env + R_uc_stranded)
• FiT-All (Renewable) (Non-Discountable | Tax-Exempt)
FiT = kWh × R_fit
• GEA-All (Renewable) (Non-Discountable | Tax-Exempt)
GEA = kWh × R_gea
• Lifeline Line (Deduction Line if Eligible, else Subsidy | Tax-Exempt)	
	• IF isLifelineBeneficiary == true AND kWh <= 100: Lifeline = -P_lifeline_tier × (Gen + Trans + SysLoss + Dist)
	• ELSE: Lifeline = kWh × R_lifeline_sub
• Government Taxes & Local Charges (Non-Discountable)
	• VAT = (Gen × V_gen) + ([kWh × R_trans] × V_trans) + ([kWh × R_ancillary] × V_anc) + (SysLoss × V_sys) + ([Dist + max(0, Senior)] × V_dist)
	• RPT = kWh × R_rpt
	• LFT = Gross_Vatable_Base × R_lft (adjusting for Senior/Lifeline discounts)
	• EnergyTax = Tiered_Energy_Tax(kWh)
	• GovTaxes = VAT + RPT + LFT + EnergyTax
• Total Amount Due
Total_Bill = Gen + Trans + SysLoss + Dist + Senior + UC + FiT + GEA + Lifeline + GovTaxes + Previous_Balance
